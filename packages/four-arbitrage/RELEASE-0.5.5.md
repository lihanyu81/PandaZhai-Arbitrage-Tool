# 0.5.5 — 总览按账户权益变化展示收益

总览“持仓估算净收益”改为“账户权益变化”：已启用平台当前权益合计减去基准权益合计，以配置的折算率统一为 USD，不再重复扣预计平仓手续费或滑点。

首次完整读取真实账户权益时建立基准并保存到本节点账本，刷新、重启及暂停/恢复不清零。显示基准金额和时间，可点击“重设收益基准”重新起算。账户配置或折算率变更时要求显式重设，避免跨账户混算。任一权益快照缺失或超过 20 秒时不展示数值，不用零替代。

权益变化包含充值、提现、资金费以及同账户其他交易的影响，不等于仅本策略的交易利润。升级前未保存基准权益，不能追溯补算；新版从首次完整快照起算。交易触发、止损风控及单个持仓周期的收益记账保持不变。

验证：388 项自动化测试，含基准持久化、缺失快照、账户变更、不重复扣估算费用；封包适配器及管理中心代理页面检查。未发送真实交易订单。
