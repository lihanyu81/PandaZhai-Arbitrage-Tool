# 0.5.29 — GRVT 接入与接口可靠性优化

- 新增 GRVT USDT 永续市场、完整盘口订阅、IOC 签名订单、真实成交与手续费对账、手动补单候选核验，以及当前标的一键清仓适配。默认不启用 GRVT，已有账户配置保持不变。
- GRVT 校验区分账户读取、签名格式与实际交易权限；交易权限未通过实盘下单验证。严格保留交易所最小数量、最小名义金额和价格步长检查。
- Entropy、QFEX、Vanta 行情正常关闭也执行重连退避，收到有效行情后才重置退避。
- QFEX 私有 REST 共享节流与错误冷却；保留原始 WS 拒单原因，拒绝冲突的重复成交。
- Entropy 下单 ACK 不再直接充当已结算成交，按原订单匹配真实成交与费用；成交记录不完整时继续待核验。
- Vanta 分页查询每页执行读取节流，检测异常订单分页。

不改变已有策略信号、STEP 或风控阈值；请求、成交核验行为有所优化，并非仅界面更新。

GRVT 通过模拟下单、恢复、清仓测试及公开只读行情验证；未执行真实账户下单、撤单或平仓。Entropy、QFEX、Vanta 手动补单支持范围未扩大。

公开包不包含散装 Python 应用源码、账户配置或密钥。PyInstaller 内嵌字节码不等于防反编译加密。

发布检查：759 项自动测试、封包 doctor、离线浏览器及当前管理中心源码配合节点封包的代理浏览器检查通过。旧管理中心封包存在路径改写兼容问题，需使用已有修复的管理中心；本次没有部署管理中心或实盘节点。
