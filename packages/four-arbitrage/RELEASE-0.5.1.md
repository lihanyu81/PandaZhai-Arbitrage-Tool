# 0.5.1 — 价差观察、累计成交量与 Telegram

- 矩阵逐方向显示当前盘口价差、同方向窗口平均 bps、买方 ask、卖方 bid、行情链路状态、最近盘口接收时间和“当前减均值”偏离。均值使用当前事件之前的样本，预热无均值时显示待采样。
- 点击矩阵方格后，机会观察固定显示所选买卖方向。各方向独立保存本次浏览会话最近 90 个盘口事件样本，不混合不同方向。
- 删除总览顶部实盘说明横幅与产品介绍区。单标的配置固定滑动均值策略、允许交易，隐藏这两个选择框；生成后仍暂停，由用户启动。
- 交易所累计步数表增加估算累计成交量（USD）：按本节点实盘历史订单实际成交量 × 成交价 × 该次折算率求和。开平仓都计入，重启不清零；模拟、零成交不计入，缺少成交价单独提示。重复查单更新同一记录，不重复累计。
- 组合醒目数值为两个方向各自“当前 bps − 同方向平均 bps”的较高值。原双腿策略的反向均值下单逻辑保持不变，下单信号单独显示，不能将展示偏离值直接理解为开仓触发值。
- 策略说明页面改为 Telegram 推送：Bot Token、Chat ID、话题 ID、开关、保存和测试。默认关闭，Token 不回显。启用后推送新成交批次、启动、暂停、风控、对账事件，不补发启用前历史事件。独立后台任务，失败重试不阻塞交易；网络结果不明时通知可能重复，可按事件编号识别。

Telegram 接口依据 [官方 sendMessage 文档](https://core.telegram.org/bots/api#sendmessage)。测试按钮使用已保存的配置。

验证：381 项自动化测试；封包适配器检查；管理中心代理浏览器的两、四、八平台配置、矩阵方向联动、隐藏默认选项、成交量列和 Telegram 配置保存。未发送真实交易订单或 Telegram 消息。
