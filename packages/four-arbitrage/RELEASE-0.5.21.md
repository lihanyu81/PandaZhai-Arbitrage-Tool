# 0.5.21 — 分平台默认手续费

默认手续费（bps）：Lighter / Robinhood Lighter 为 0，PopDEX / Vanta 为 3，Arcus 为 2，Entropy / QFEX 为 1。未指定的 Decibel 保留原默认值。

用于持仓收益中的预估平仓手续费及模拟成交费用，不扣减实盘下单信号，不覆盖历史实际成交手续费。滑点预留规则保持不变。

新配置及缺少 fee_bps 的平台配置采用新默认值；已保存的显式费率保留，现有节点需按自身配置更新。

验证：457 项测试通过，包含默认值、部分配置补齐、显式费率保留及收益拆分；封包浏览器检查通过。未提交真实交易订单。
