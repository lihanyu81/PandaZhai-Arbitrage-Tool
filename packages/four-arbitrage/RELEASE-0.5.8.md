# 0.5.8 — Arcus 手动补单自助恢复与拒单原因

持仓与恢复页为需要处理的 Arcus 组合增加“关联手动补单”：输入交易所订单 ID，预览成交方向、数量、价格和手续费，确认后重新查询并关联，再核对全部平台仓位与挂单。保持暂停，用户自行恢复交易。

首版限于 Arcus 开仓腿零成交、另一腿完整成交后的等量完整补单。拒绝部分补单、反向补单、数量/市场不一致、重复使用订单、已有挂单或其他平台账本差异。原订单有活动状态或任何成交时禁止关联；原请求查无记录且仍为 UNKNOWN 时，必须由用户在交易所确认原请求已拒绝且不会成交，并显式确认，不能仅依据总仓位平衡。保留关联前完整操作备份、原始请求/结果、补单和成交 ID、用户确认记录。

Arcus 401/403/422 明确请求拒绝记录为 FAILED，保留 HTTP 状态码及脱敏响应；限流、服务端错误与连接不确定仍查单，不重复提交。后续查单不再覆盖丢失原始提交错误。

验证：406 项完整回归测试通过，增加接口鉴权/CSRF 测试后恢复专项 14 项通过；封包管理中心浏览器验证预览和确认交互（模拟响应），未发送真实交易订单。
