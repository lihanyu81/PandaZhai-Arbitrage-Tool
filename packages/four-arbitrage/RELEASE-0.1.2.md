# 四平台套利节点 0.1.2

补充停止/退出后的收益核验，修复未知订单期间可能显示不完整收益的问题。

- 任一参与订单仍未确认时，组合收益显示“待核对”；完整成交返回后自动恢复计算。
- 手动退出和风险退出共用结算路径，按所有开平仓成交与手续费汇总收益。
- 已平仓组合不依赖实时盘口显示收益；重启后可从持久化成交记录恢复。
- 保留 0.1.1 的 QFEX 回报兼容、独立保存每条腿结果和每 30 秒自动查单；不会因查单自动重发订单或恢复交易。

验证：68 项自动测试通过。新增覆盖全部 12 个买卖方向的手动/风险退出、部分成交多轮退出、四家平台延迟回报、重复查单和重启后收益。封包自检、演示模式浏览器验证通过。

收益口径：未平仓为按盘口退出的估算；已平仓为该组合开平仓成交现金流减手续费，不包含资金费和人工交易。测试使用假交易所与演示模式，没有发送实盘订单。

独立节点，默认演示模式且暂停。发行包不含松散 Python 应用源码或账户运行数据；不能保证防止专业反编译。
