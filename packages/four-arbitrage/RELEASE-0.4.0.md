# 混合套利节点 0.4.0 — 独立 STEP

每个交易所组合可设置每步数量和最大正负步数（1–20）。新建组合默认使用 STEP 模式，批量生成页面可设置统一初始上限，生成后在每组编辑中独立修改。

- 买 A / 卖 B 为正步，卖 A / 买 B 为负步。
- 同向信号一次加一步，达到上限停止加仓；反向信号先按先入先出退出一笔已成交步仓，回到 0 后下一次信号才可反向开仓，不跨零开反向仓。
- STEP 根据组合的真实成交账本计算，不使用平台净仓位推测；共享平台上的组合相互抵消也分别记步。
- 部分成交显示小数步，单腿不平衡或订单未确认显示待核对，禁止继续加仓；不伪造整数步数。
- 下单前写入客户订单 ID，恢复时沿用查单；重复恢复不重复计步。重启后保持暂停，已有持仓需先对账。
- STEP 模式按反向信号减步，保留风险退出和手动退出，不再同时使用旧周期模式的自动净收益止盈。暂停调度也暂停 STEP 信号减步；已有持仓风险监控继续。
- 事件中记录 STEP 前后值及确认状态。

兼容：旧组合保留原周期模式，显示“旧周期”。无持仓时编辑并填写最大正负步数、保存即可切换 STEP；有持仓禁止切换管理模式或改变每步数量，上限不可调到低于已有仓位步数。

验证：原 326 项回归测试及 8 项 STEP 专项测试通过，覆盖正负上限、逐步反向、部分成交、未知订单恢复、重启恢复、信号消失、共享平台净仓抵消、并发提交与参数限制。浏览器验证批量最大步数及组合独立编辑。未发送实盘订单。
