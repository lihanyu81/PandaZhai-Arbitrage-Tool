# 0.5.0 — 交易所步数与串行对账

- 运行模式固定为真实交易，移除演示/模拟/实盘选择。新装、升级及重启后均暂停，用户点击“启动交易”才开启策略调度。
- 在“交易所配置”分别设置每家交易所的最大正负步数，默认 ±5，可设置为 ±20。所有组合统一每步数量；同一交易所各组合的净仓位合计除以每步数量，得到该所当前 STEP。
- 达到正向或负向上限时，只允许减少该所已有净仓位；不允许继续增加或单笔跨越零位反向加仓。另一腿也必须满足其交易所限额。
- 组合页面保留当前组合 STEP，取消每组合步数上限。概览新增各交易所当前 STEP、上限及限制状态。
- 不同策略严格串行。同一策略两腿并发提交，订单终态、实际仓位与未完成挂单核验通过之后，下一策略才可下单。部分成交、结果未知、仓位延迟或残留挂单均阻止放行；对账超时暂停，重启后仍须对账。
- 价差信号仍沿用滑动均值偏离，不扣预估手续费。实际成交手续费继续用于收益记账。

升级保留账户和策略配置；旧的组合上限不再生效。请在启动前设置各所上限。现有组合数量不同的旧配置需要先统一每步数量。历史模拟持仓不会被转换为真实平仓单。

验证：自动化回归、管理中心代理浏览器、两/四/八平台组合配置、交易所上限保存、跨策略限额、对账串行等待与重启恢复。未发送真实交易订单。
