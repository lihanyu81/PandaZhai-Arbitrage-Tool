# 0.5.9 — 平台仓位面板调整风控下限

平台实际净仓位新增实时强平距离/账户保证金缓冲百分比与各平台独立下限，支持在面板点击“调整”保存，持仓期间也可修改。旧配置按原统一下限继承，未单独修改的平台保持原值。有效范围为大于 0、不超过 100；数据缺失或过期显示待读取，无仓位显示无持仓。

下单前校验和持仓风险检查使用同一平台下限。保存后重新检查风险，实际指标达到或低于下限时仍触发相关持仓风险退出。已有下单或对账期间不能并发修改。

移除账户风控设置中的每个持仓周期估算止损（USD）输入和按该阈值自动退出的执行规则；旧 max_loss 配置仅兼容读取，不再触发该止损。其他风控、对账、手动退出保持不变。

验证：415 项自动化测试通过，涵盖阈值独立性、持仓时保存、持久化、无效值、风险显示与旧 USD 止损不再触发；封包管理中心代理浏览器验证调整保存与字段移除。未发送真实交易订单。
