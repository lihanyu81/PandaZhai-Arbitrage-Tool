# 0.5.11 — 风险数据时钟分离与等待日志合并

按用户设置，将标记价超过 20 秒未更新判为过期，后台持仓风险复查间隔调整为约 30 秒。下单前仍即时核验风险，账户面板刷新频率保持不变。

Lighter 分别跟踪账户快照接收时间、包含强平价的账户快照确认时间、标记价更新时间，不再把标记价时间混作整个仓位的更新时间。账户/强平价仍须有近期有效快照（20 秒）；强平价不变并不意味着数据过期。接口响应不提供某项独立变化时间时，以成功查询确认时间标记，不伪造交易所更新时间。

等待日志写明缺失、时间戳缺失、时间戳异常或过期的具体项及各数据年龄。相同连续等待过程仅记录开始与恢复，期间原因和年龄仍在状态接口更新，不按秒数变化刷日志。真实风险超限、订单未确认及手动暂停保护保持不变。

验证：426 项自动化测试通过，包含 20 秒边界、各时钟独立失效及同一等待去重；只读实盘确认三项年龄独立返回；封包管理中心浏览器检查通过。未发送真实交易订单。
