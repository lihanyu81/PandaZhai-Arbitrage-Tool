# 0.5.25 — 状态快照与行情连续性修复

- 单次状态快照复用账本读取结果，快照结束立即释放，不跨请求缓存仓位；按持仓周期查询操作记录并使用索引。
- 页面状态刷新串行执行，完成后再计时；保留操作触发的刷新与翻页，避免慢接口请求重叠及响应持续被丢弃。
- 正常盘口连接默认不再每 120 秒强制重连。心跳超时、订阅异常、断线后完整盘口核验保持不变，显式配置定期重连仍受支持。
- 不修改价差算法、Decimal 精度、滑动样本数量、订单条件、STEP、手续费或账户风控阈值。

验证：476 项测试通过；离线响应式界面检查通过；慢响应及翻页模拟检查通过。相同账本副本的快照返回内容除时间戳外与修改前一致；本地剖析约 2.78 秒降至 0.026 秒（环境相关，不代表线上延迟承诺）。未发送真实测试订单。
