# 0.5.26 — 当前标的一键平仓

顶部增加一键平仓入口，输入标的确认后暂停新增，依次处理启用平台当前标的全部实际净仓位，包含手动补单。其他标的不在范围内。只减仓订单按新读到的实际剩余仓位构造，不逐个退出虚拟组合。

每个请求 ID 在提交前落盘；超时先查原订单，未确认不重复提交。重复点击返回同一任务，重启后保留任务并等待用户继续核验。挂单撤销不支持、拒单、未知订单、行情或账户不可用时明确显示部分未完成，其他可处理平台继续退出。部分成交有限次处理后仍有残余时，用户可继续核验/平剩余仓位。

所有平台两轮实际仓位与挂单核验归零后才显示成功并归档当前标的组合；始终保持暂停。批量成交单独持久记录、成交量计入平台累计值；不编造每组合平仓成交或收益，无法分摊的周期收益明确显示“批量平仓 · 收益未分摊”。

保留原认证和 CSRF 校验；平仓未完成时禁止启动、修改组合与切换账户/平台/模式；允许在可识别为同一账户的前提下更新密钥以恢复权限。后台不自动触发本功能。

测试仅使用模拟账户与全拦截离线页面；没有向真实交易所提交平仓测试订单。不能保证交易所一定接受订单或立即全部成交。
