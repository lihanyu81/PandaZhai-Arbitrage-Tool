# 混合套利节点 0.3.0

新增 Decibel、Vanta、PopDEX、Arcus，合计支持八家平台。任意启用 2–8 家，仅计算启用平台交集，最多 28 组组合、56 个方向；每组独立目标、滑动均值入场、共享净仓位核验、订单恢复及退出记账沿用混合节点。

新增接入配置：

| 平台 | 配置 | 行情要求 |
| --- | --- | --- |
| Decibel | 子账户地址、Geomi API Key、API Wallet 私钥 | Geomi API Key 必填 |
| Vanta | Orderly Account ID、Orderly Key、Orderly Secret | Account ID 必填 |
| PopDEX | 账户地址、Signer 私钥 | 行情公开；实盘须通过原钱包白名单 |
| Arcus | 账户地址、子账户 Index、API Key、API Private Key | 行情公开；保留全仓永续账户限制 |

复用四家原双腿节点的市场规范化、价格/数量精度、账户、签名提交、订单终态及成交恢复代码。新增平台不会隐式依赖 Lighter 的可交易标的；基于平台各自的合约目录建立映射。

旧配置自动补齐新增平台字段，新增平台保持未启用。原启用平台、凭证、监控组合和账本保留。安装目录、服务名与安装参数继续使用 four-arbitrage，避免迁移原节点身份。

验证：325 项混合节点测试、116 项原适配器专项测试、4 项管理中心注册/白名单测试通过。Vanta 原双腿服务层的退出测试未用于此封包，其对应行为由混合节点退出测试覆盖。真实封包浏览器验证八平台、28 组、56 个方向及八行账户。

只读实测：Arcus 59 个市场及 BTC 盘口、PopDEX 66 个市场及 BTC 盘口、Vanta 133 个市场；数量为测试时快照。Decibel 未提供 Geomi API Key，返回明确缺少凭证错误。未使用用户账户对新增平台发送实盘订单，未完成四家新增平台的真实成交验证。
