# 四平台套利节点 0.1.0

Entropy（Hyperliquid io DEX）、Lighter 主网、Robinhood Lighter、QFEX 独立套利节点。

- 单标的生成 6 组平台组合，比较 12 个买卖方向；每次优先执行达到目标的一组买卖两腿。
- 各组独立目标净 bps、数量和限额；预留开平仓手续费与滑点，不包含资金费。
- 汇总四平台仓位，并逐平台核对真实仓位与成交账本；人工补仓不会当作程序成交。
- 缺失或过期账户数据标记为未知；部分成交、未知订单与账本不一致会阻止新增交易。
- QFEX 动态合约精度与价格区间、IOC 限价、完整成交核验、脱敏拒单原因记录。
- 日夜主题、2FA 登录、模拟交易、重启对账恢复。

验证：35 项自动测试、四家公开市场与 WS 行情读取、封包后独立启动和浏览器流程通过。尚未完成四平台真实资金开平仓验收。

默认演示模式且暂停。当前为独立节点版，不包含管理中心注册组件；与现有双平台节点分开部署。

封包不分发散装 `.py` 应用源码、数据库或账户配置。程序代码以字节码嵌入可执行文件；普通解压不会得到 Python 源文件，但专业提取或反编译仍然可能。前端 HTML/JS/CSS 属于浏览器必须读取的资源。
