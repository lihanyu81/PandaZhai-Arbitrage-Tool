# 混合套利节点 0.2.0

支持从 Entropy、Lighter、Robinhood Lighter、QFEX 中启用任意 2–4 家平台。共同市场只计算已启用平台的交集，分别生成 1、3、6 组策略。每组可单独填写默认目标 bps，生成后仍可独立编辑。

新建组合默认使用原双腿的滑动窗口入场策略：

- 买 A / 卖 B 的原始价差 = B 买一 − A 卖一。
- 双方向都按行情事件采样，相同行情不重复计数；当前样本不进入自己的触发基准。
- 入场门槛 = 负反方向历史均值 + 卖方买一 × 目标 bps / 10000。等价于旧双腿实现中“同方向均值 + 目标 − 双方向均值之和”。
- 默认窗口 2000、预热 100，可配置；预热完成前不开新仓。
- 保留盘口时效、时间差、资金和账户核验。退出仍按混合节点的组合成交账本与可执行平仓净收益核验，不等同于完整复制旧节点的 STEP 状态机。

旧组合保留固定净价差模式，避免静默改变现有策略。用户可编辑为滑动策略，或者在无未结算持仓时重新生成。

监控表显示双方向原始价差、历史基准、触发门槛与预热数量；矩阵保留扣费后的绝对价差并明确标注，同时显示买方卖一与卖方买一及行情来源。

演示模式使用程序生成行情。若只想看真实行情并模拟交易，请在平台接入中选择“真实行情 · 模拟成交”（paper）并保存；无需切换为实盘。手续费请按账户实际费率填写，默认参数不是交易所费率承诺。

验证：83 项测试通过，覆盖任意 2/3/4 平台组合、独立目标、禁用平台不影响交集、滑动基准排除当前样本及重复采样保护。真实封包管理中心代理浏览器验证通过。未发送实盘订单。
