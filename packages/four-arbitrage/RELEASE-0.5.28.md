# 0.5.28 — PopDEX 文本心跳修复

行情流与账户订单/成交流每 30 秒发送文本 `ping`，收到 `pong` 后单独处理，不进入 JSON 解析。发送或回复超过 10 秒失败时关闭连接并重订阅；保留现有 WebSocket 协议 Ping、盘口连续性和账户对账规则。连接结束或任务取消时清理心跳任务；账户流正常关闭时也清除订阅就绪状态并重连。

修复此前只发送协议 Ping、未满足 PopDEX 文本心跳要求导致约两分钟周期断开的问题。不修改交易信号、手续费、STEP、下单或风控阈值。

依据：https://popdex.xyz/docs/api/websocket/intro

验证使用模拟 WebSocket 与只读行情订阅，不发送真实测试订单。
