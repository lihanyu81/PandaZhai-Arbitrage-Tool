# 0.5.16 — Arcus 手动补单直接选择成交记录

“关联手动补单”自动读取当前 Arcus 子账户的订单和成交记录，按失败开仓的标的、方向、数量和时间筛选，并显示时间、数量、成交均价和手续费。用户选择对应成交后预览并确认，无需从 Arcus 前端查找或输入订单号。

已关联订单、节点自身请求、部分成交和不完整成交明细不会列入候选。候选列表不修改账本；预览与确认仍重新核验原请求、成交记录、实际仓位及挂单。原请求未知时仍需核验或由用户明确确认已拒绝，不能仅凭仓位平衡关联。关联后保留原请求及审计备份，保持暂停。

验证：全套 451 项测试通过，最终候选逻辑 25 项专项测试通过，封包浏览器检查覆盖读取候选、选单、预览与确认。未提交真实交易订单。
