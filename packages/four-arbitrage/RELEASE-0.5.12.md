# 0.5.12 — 持仓期间更新同账户 Arcus API 密钥

暂停后，有持仓时允许仅更新 Arcus API Key 和签名私钥；钱包地址、子账户 Index、启用平台、模式及其他配置必须不变，正在执行或对账时仍禁止保存。新密钥先通过本地配对、官方注册列表、ACTIVE 状态、有效期和子账户范围检查，再保存配置；失败保持旧配置。

保留已有成交、补单、持仓与对账记录，不自动恢复交易。同账户密钥轮换保留有效的权益收益基准。其他平台的持仓期间凭据轮换暂未开放。

Arcus 常规接入校验也增加注册状态、有效期和子账户范围检查，防止仅公开账户读取成功便放行未注册 Key。此校验不提交试单，不声称已验证真实成交。

验证：432 项全量回归测试通过，新增注册状态专项后密钥更新专项 11 项通过；封包管理中心代理浏览器检查通过。未发送真实交易订单。
