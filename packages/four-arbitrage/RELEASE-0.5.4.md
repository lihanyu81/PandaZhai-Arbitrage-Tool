# 0.5.4 — 自动处理延迟成交回报

实盘批次收到 UNKNOWN 等未确认回报后，在同一个策略执行锁内自动查单、核对实际仓位并检查挂单，最多等待 60 秒。仅查原客户订单号，不自动重发。

订单终态及账户核验通过且双腿完整匹配后，继续原调度，无需每次人工核对并恢复。等待期间其他策略不能下单。用户在等待过程中手动暂停，核验完成后仍保持暂停。

持续超时、部分成交或不平衡仓位仍暂停并提示处理。其他风控暂停、程序重启暂停不自动解除。本次不改变价差信号、门槛、每所步数和风险退出规则。

验证：386 项测试覆盖通过（384 项全量回归及新增两项自动查单重试/取消场景），包括不重发、手动暂停不被覆盖、成功后下一策略放行、超时及重启保护；封包适配器与管理中心代理浏览器检查。测试未发送真实交易订单。
